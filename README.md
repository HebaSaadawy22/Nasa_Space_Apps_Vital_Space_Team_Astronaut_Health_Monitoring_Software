# Orbital Health Control · ISS

Frontend dashboard for monitoring astronaut health aboard the ISS.

- Live ISS position from [wheretheiss.at](https://wheretheiss.at) (falls back to an orbit simulation)
- Simulated crew vitals, space effects and cabin environment, with alerts and advice
- Plain HTML/CSS/JS, no build step: open `index.html`

> Demo only. Crew data is simulated, not real medical data.
